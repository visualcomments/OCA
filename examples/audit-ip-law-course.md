## 2. Критические находки (BLOCKER)

Формальных блокеров сканер не нашёл (LICENSE есть, README есть, занятия есть).
Но по существу **один блокер содержательный**:

### B-1. Верификатор цитат не проверяет координаты — 17/26 ссылок ведут не туда

**Что:** `tools/verify_quotes.py:114-115` формирует строку
`"OK (cited #N, actual #M)"`, но **не увеличивает счётчик `fails`**. Отчёт
печатает «неудач: **0**», хотя координаты расходятся.

**Где:** `verification/REPORT.md:8-31`, `tools/verify_quotes.py:113-118`

**Факты** (из самого отчёта верификации):

|---|---|---|

| `08_zaschita_i_cifra.md` | #842 | #1812 |
| `09_patentnoe_pravo_istoriya.md` | #921 | #1891 |

| `16_itogovoe_zanyatie.md` | #889 | #1859 |

Плюс **5 цитат вообще без координаты** (`cited #None`): ст. 1225, 1259, 1255,
1363, 1477 ГК РФ.

Итого: **4 корректных, 17 неверных, 5 без координаты** из 26.

**Почему важно:** читатель курса, переходя по координате «файл · фрагмент #N»,
попадает в другое место корпуса. Хуже — `make verify` и README («0 ошибок»)
создают ложную уверенность в проверенности. Для курса, который продаёт
верифицируемость как ключевое свойство, это подрыв доверия.

**Как исправить:**
1. В `verify_quotes.py` добавить в `fails` случаи `found_chunk != cited`
   (и `cited is None` при наличии `found_chunk`).
2. Перегенерировать `verification/REPORT.md`.
3. Обновить координаты в лекциях на `actual` (скриптом, не руками).
4. Переформулировать README: не «0 ошибок», а «0 расхождений текста и
   координат» — с указанием, что проверяется.

## 3. Существенные находки (MAJOR)

### M-1. Нет лицензии на учебный контент при CC BY-SA источниках

**Где:** корень репозитория (нет `LICENSE-CONTENT`), `README.md:67`
**Факт:** `LICENSE` = GPL-3.0 (для кода). Контент занятий (`lectures/*.md`)
построен на статьях Wikipedia **CC BY-SA 4.0** (`CORPUS.md`, `PROVENANCE.md`).
GPL-3.0 — лицензия ПО; она не покрывает текстовые материалы и плохо
совместима с CC BY-SA для производного контента.
**Последствие:** неясен правовой режим самих лекций; CC BY-SA требует
распространения производных работ под той же лицензией.
**Исправить:** добавить `LICENSE-CONTENT` (CC BY-SA 4.0) и явно разделить
«код / контент» в README. Шаблон есть в скиле `oca-course-improve`.

### M-2. Критериев оценивания нет ни в одном занятии

**Где:** все `lectures/*.md` (проверено сканером: флаг `G` установлен лишь в
4 из 16)
**Факт:** syllabus.md:46 объявляет форму контроля — «итоговое эссе/реферат»,
но ни рубрики, ни шкалы, ни весов.
**Последствие:** студент не знает, как оценивается работа; преподаватель —
по каким критериям ставить балл.
**Исправить:** добавить рубрику в занятие 16 (итоговое) и краткие критерии
для заданий остальных занятий.

### M-3. Нет CI — проверки не воспроизводятся автоматически

**Где:** отсутствует `.github/workflows/`
**Факт:** есть `make verify`, но он запускается вручную и (см. B-1)
не проверяет то, что заявлено.
**Исправить:** workflow, запускающий `make verify` + проверку ссылок +
валидацию ноутбуков. Шаблон — `ci.yml.tpl` из `oca-course-improve`.

### M-4. Демо-ноутбук не исполнен

**Где:** `notebooks/law_graph_predictive_demo.ipynb`
**Факт:** 4 кодовых ячейки, у всех `execution_count=None`, выходов нет.
**Последствие:** нельзя понять ожидаемый результат без запуска; «демо»
не демонстрирует.
**Исправить:** исполнить ноутбук и закоммитить с выходами, либо явно
пометить в README как «запускается локально».

### M-5. `make search QUERY="..." -k 5` из README не работает

**Где:** `README.md:57`, `Makefile:26`
**Факт:** в Makefile переменная `K` не определена (заголовок `K ?=` отсутствует),
а в README команда показана как `make search QUERY="товарные знаки" -k 5` —
`-k 5` уходит в `make`, а не в `rag_search.py`. Скрипт получит пустой `-k`.
**Исправить:** добавить `K ?= 5` в Makefile и поправить README на
`make search QUERY="..." K=5`.

## 7. Суждения (JUDGEMENT)

- **[judgement]** Курс перегружен инженерной обвязкой относительно
  педагогического ядра: `law_graph/`, RAG-API, зеркала навыков в трёх
  каталогах — при этом рубрики оценивания нет ни в одном занятии.
  Приоритет стоит сместить с инфраструктуры на оценивание.
- **[judgement]** Раздел «Источники и свидетельства» в занятии 01 выглядит
  как результат OCR-конвейера: первая цитата (ст. 1225 ГК РФ) обрывается на
  полуслове «предос» и не имеет координаты. Вероятно, требуется ручная
  вычитка блока цитат во всех занятиях.
- **[judgement]** Заявление README «0 ошибок после правок» (строка 25)
  вводит в заблуждение именно потому, что верификатор считает ошибкой
  только расхождение текста, но не координаты. Формулировку стоит
  уточнить, а не удалять.
