## 2. Критические находки

Всего **8 блокеров** в 8 из 14 курсов — и все одного типа.

### B-1. Нет файла LICENSE (8 курсов)

**Где:** `ai-studio-course`, `flutter-mipt`*, `intro-to-cloud-tech`, `intro-to-ml-dl`,
`machine-learning-course-brain-lab-mipt`, `ml-course-hse`,
`optimization-methods-course-brain-lab-mipt`, `unn-itmm-ycloud`
(*у `flutter-mipt` есть `LICENSE-code.md` и `LICENSE-text.md`, но сканер не
нашёл канонического `LICENSE` — см. §6, это уточнение, а не ошибка курса)

**Почему важно:** README библиотеки прямо обещает: «Все курсы публикуются как
авторские. Интеллектуальная собственность на контент остаётся на стороне
преподавателя» (`README.md:245`). Юридически это утверждение **ничем не
подкреплено**: без файла лицензии неясно, что разрешено делать с материалами —
а библиотека призывает «взять ваш курс и запустить его в следующем семестре»
(`README.md:239`). Преподаватель другого вуза не может понять, вправе ли он
использовать материалы.

**Как исправить:** добавить в каждый курс `LICENSE` (код) и `LICENSE-CONTENT`
(материалы, обычно CC BY-SA 4.0 или CC BY 4.0). Для `flutter-mipt` достаточно
добавить канонические имена.

## 3. Существенные находки (MAJOR)

### M-1. Нет программы курса (syllabus) — 12 из 14

**Код:** `no-syllabus`. **Где:** почти все курсы.
Библиотека требует от авторов «силлабус по неделям» (`README.md:251`), но
собственные курсы его не содержат. Единственное исключение —
`machine-learning-course-brain-lab-mipt` (PDF «Программа.pdf»).

### M-2. Битая относительная ссылка — 51 случай

**Код:** `broken-link`. Самый массовый дефект. Это прямые потери для читателя:
ссылка из README на занятие или ресурс не работает.

### M-3. Ноутбуки не парсятся — 10 случаев

**Код:** `bad-notebook`. Повреждённый JSON в `.ipynb` — ноутбук не открывается
ни в Jupyter, ни у студента.

### M-4. Нет файла окружения при наличии кода — 6 курсов

**Код:** `no-environment`. Есть Python-код и ноутбуки, но нет
`requirements.txt` / `environment.yml`. Студент не может воспроизвести.

### M-5. PDF-only материалы — 4 курса

**Код:** `pdf-only-materials`. Лекции только в PDF: текст не индексируется,
поиск невозможен, цитирование неверифицируемо. Именно это обрушивает ось
«Содержание» (1.71) и делает бессмысленными обещания AI-ассистента.

### M-6. Нет критериев оценивания — 3 курса

**Код:** `no-grading`, `no-assignments`.

## 5. Находка по самому репозиторию каталога

Репозиторий `open-education-club-by-yandex` — это **не курс, а каталог**, и
OCA к нему напрямую неприменим (нет занятий). Но проверка выявила:

- `main` содержит **только `README.md`**;
- ветка `add-catalog-mcp-server` (коммит `4b8d267`) добавляет `catalog.json`,
  `mcp/catalog-mcp.py`, `mcp/requirements.txt`, `mcp/README.md` — **387 строк,
  не влито**;
- README в `main` ссылается на 14 курсов, и **все 14 URL резолвятся** — каталог
  не содержит битых ссылок (проверено `git ls-remote` по каждому слагу);
- README заканчивается **без перевода строки** в конце файла (`\ No newline`).

**Рекомендация:** влить `add-catalog-mcp-server` в `main` — это превращает
библиотеку из списка ссылок в агентно-доступный каталог и закрывает
собственное обещание платформы.

## 6. Метод и ограничения

**Что сделано:**
1. Все 14 URL каталога проверены `git ls-remote` — **14/14 резолвятся**.
2. Все 14 курсов склонированы (`--depth 1`) и просканированы `oca_scan.py`.
3. Прочитаны: README каталога (271 строка), `catalog.json` (14 записей),
   `mcp/requirements.txt`, diff ветки MCP.
4. Выборочно изучена структура курсов (PDF/ноутбуки/русские имена папок).

**Ограничения:**
- Сканер оценивает **детерминированную часть** (наличие артефактов, ссылки,
  гигиена ноутбуков). Содержательное качество лекций **не оценивалось**:
  тексты PDF не извлекались.
- Число «занятий» — эвристика. Для курсов со смешанной структурой
  (`deep-vision-and-graphics-shad` = 2, `speech-processing-shad` = 1) значение
  занижено: материалы лежат вне распознаваемых контейнеров.
- У `flutter-mipt` лицензии есть под нестандартными именами —
  блокер `no-license` для него следует читать как «нет канонического имени».
- Правовая корректность содержания не проверялась — вне рамок OCA.

## 7. Суждения (JUDGEMENT)

- **[judgement]** Разрыв между обещанием и реальностью — главный риск
  библиотеки. Платформа позиционирует AI-ассистентов, нейропроверки и
  автопроверку лабораторных, но ось «Агент-готовность» = 0.25 из 5, а
  «Воспроизводимость» = 0.90. Инфраструктура опережает готовность контента.
- **[judgement]** ИИ-ассистент, отвечающий студенту по курсу, физически не
  сможет работать с PDF-only лекциями без предварительной индексации. Это
  блокирующая зависимость для продукта, а не косметика.
- **[judgement]** Приоритет стоит сместить с привлечения новых курсов на
  «доведение до агентной готовности» уже опубликованных 14. Новый курс без
  лицензии и программы добавляет ту же проблему.
